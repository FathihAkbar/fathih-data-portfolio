# Supermarket Sales Analysis

## Overview

Exploratory analysis of supermarket transaction data to identify sales, product, customer, payment, and time-based patterns.

## Objective

Analyze:

- Branch performance
- Product performance
- Customer behavior
- Payment methods
- Transaction timing
- Sales correlations

## Dataset

Source: Kaggle – Supermarket Sales

## Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Results

- Total transactions: 1,000
- Total sales: $322,966.75
- Highest-performing branch: Giza
- Highest-sales product line: Food and beverages
- Most frequently used payment method: Ewallet
- Peak transaction hour: 19:00
