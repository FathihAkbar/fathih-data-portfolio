# Customer Churn Prediction

## Overview

This project develops a machine learning system to predict whether a telecommunications customer is likely to churn.

The project follows a complete data science workflow, including exploratory data analysis, feature engineering, preprocessing, model comparison, cross-validation, hyperparameter tuning, threshold optimization, feature interpretation, and customer risk profiling.

The main goal is not only to predict churn, but also to identify high-risk customers and translate model outputs into actionable retention strategies.

## Objectives

- Understand customer characteristics and churn patterns
- Perform exploratory data analysis
- Identify variables associated with customer churn
- Perform feature engineering
- Build and compare multiple classification models
- Apply cross-validation and hyperparameter tuning
- Optimize the classification threshold
- Interpret important predictive features
- Develop customer risk categories
- Generate business recommendations

## Dataset

**Dataset:** Telco Customer Churn

The dataset contains telecommunications customer information such as:

- Customer demographics
- Contract information
- Internet service
- Payment method
- Tenure
- Monthly charges
- Total charges
- Additional services
- Churn status

The dataset contains:

- **7,043 customers**
- **21 original variables**

Additional engineered features were created during the analysis.
