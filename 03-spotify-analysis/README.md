# Spotify Music Analysis

## Overview

Analysis of Spotify tracks based on popularity, genre, artist performance, and audio characteristics.

## Objective

Analyze:

- Track popularity
- Genre performance
- Artist performance
- Audio features
- Correlation between audio features and popularity

## Dataset

Source: Kaggle – Spotify Tracks Dataset

## Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Results

- Original records: 114,000
- Cleaned records: 113,999
- Unique tracks: 89,740
- Number of genres: 114
- Average popularity: 33.24
- Most popular genre by average popularity: pop-film
- Highest average artist popularity among artists with at least five tracks: Olivia Rodrigo
