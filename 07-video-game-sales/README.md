# Video Game Sales Analysis with SQL

## Overview

SQL-based analysis of video game sales across platforms, genres, publishers, and regions.

## Objective

Analyze:

- Platform performance
- Genre performance
- Publisher performance
- Regional sales
- Sales trends over time

## Key Results

- Top platform: PS2
- Top genre: Action
- Top publisher: Nintendo
- Highest-sales region: North America
- Sales peaked around the late 2000s in the analyzed dataset.
