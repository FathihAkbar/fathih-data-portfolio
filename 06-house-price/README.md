# House Price Prediction

## Overview

A machine learning regression project for predicting residential house sale prices.

## Objective

Analyze housing characteristics and build regression models to predict SalePrice.

## Models

- Linear Regression
- Random Forest Regression

## Results

### Linear Regression

MAE: $24,935.83  
RMSE: $39,568.64  
R²: 0.7959

### Random Forest

MAE: $19,082.67  
RMSE: $29,738.16  
R²: 0.8847

Random Forest was selected as the final model.

- OverallQual
- GrLivArea
- TotalBsmtSF
- 1stFlrSF
