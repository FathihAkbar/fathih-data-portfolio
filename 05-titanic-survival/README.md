# Titanic Survival Prediction

## Overview

A machine learning classification project that predicts whether a Titanic passenger survived.

## Objective

Analyze passenger characteristics and build classification models to predict survival.

## Models

- Logistic Regression
- Decision Tree

## Evaluation

Metrics:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Results

### Logistic Regression

Accuracy: 80.45%

### Decision Tree

Accuracy: 78.77%

Logistic Regression was selected as the final model.
